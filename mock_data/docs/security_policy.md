# RiskFlow AI - Corporate Security Policy

**Effective Date:** January 1, 2026

## 1. Data Encryption
All customer and internal data at rest must be encrypted using AES-256 standard.
Data in transit across all external and internal networks must be protected using TLS 1.3 or higher.

## 2. Access Control
RiskFlow AI enforces Role-Based Access Control (RBAC) across all systems. Multi-Factor Authentication (MFA) is mandatory for all employee and contractor accounts accessing production environments or sensitive data.

## 3. Infrastructure & Hosting
Primary application and database hosting is located in AWS US-East-1. Disaster Recovery (DR) and backups are maintained in AWS US-West-2. Our infrastructure is exclusively contained within audited SOC 2 compliant data centers.
