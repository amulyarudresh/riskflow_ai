# RiskFlow AI - Third-Party Vendor Security Guidelines

To partner with or provide services to RiskFlow AI, all vendors must adhere to the following baseline security requirements.

## 1. Compliance Certification
Vendors processing any sensitive or PII data must hold a current SOC 2 Type II certification. A copy of the latest report must be provided during the vendor onboarding process.

## 2. Security Testing
Vendors must conduct at least one comprehensive annual penetration test performed by an independent third party. Executive summaries of findings must be shared with the RiskFlow AI security team upon request.

## 3. Software Supply Chain
Any third-party code libraries incorporated into services provided to RiskFlow AI must be scanned daily using automated Software Composition Analysis (SCA) to identify known vulnerabilities.

## 4. Sub-processors
Data sharing with any 4th-party sub-processors is strictly prohibited unless explicit written consent is obtained from RiskFlow AI.
